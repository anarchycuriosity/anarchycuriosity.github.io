func NewWithClaims(method SigningMethod, claims Claims) *Token {
    return &Token{
        Header: map[string]interface{}{
            "typ": "JWT",
            "alg": method.Alg(),
        },
        Claims: claims,
        Method: method,
    }
}

这个语法我有点懵逼,主要是空接口,为什么Header要这样设计 因为在Go中,任何类型的值都可以赋给空接口.空接口不是没有值,而是变量可以保存不同类型的值 也就是它的意思是

一个键固定为字符串、值可以存放不同类型数据的字典。

第三方库的签名方法这个对象->如何使用接口

我不是很懂method和Alg()是什么关系,method是算法的代码逻辑和数据结构,然后Alg()就是为了得到这个算法的名字吗,以字符串的形式

我们来看这个第三方库

type SigningMethod interface {

    Verify(signingString, signature string, key interface{}) error // Returns nil if signature is valid

    Sign(signingString string, key interface{}) (string, error)    // Returns encoded signature or error

    Alg() string                                                   // returns the alg identifier for this method (example: 'HS256')

}

也就是说，一个具体类型只要实现这三个方法，就可以作为 SigningMethod 使用。

方法 职责
Alg() 返回算法名称，例如 "HS256"
Sign() 使用算法和密钥生成签名
Verify() 使用算法和密钥验证签名

比如
