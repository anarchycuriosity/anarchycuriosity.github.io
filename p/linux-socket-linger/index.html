linger定义 

1
2

struct linger
{
    int l_onoff;
    int l_linger;
};
struct linger tmp = {0, 1};

wait 是一个动作：线程执行到这里，可能停下来等某件事。

SO_LINGER 是一个策略配置：以后这个 socket 被 close() 时，内核应该怎么处理“还有数据没发完”的情。

socket 内核对象
┌──────────────────────┐
│ TCP 状态             │
│ send buffer          │
│ recv buffer          │
│ socket options       │
│                      │
│ SO_LINGER:           │
│   enabled = true     │

          ▲

        close(fd)

          ▼
内核根据这里保存的策略
决定关闭行为

所以 linger 本身甚至不是“一个正在运行的东西”,它只是socket内核对象上的一个配置
