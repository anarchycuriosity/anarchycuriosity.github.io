C++ 智能指针｜unique_ptr 所有权转移与 shared_ptr 引用计数

2025-11-11
阅读时长: 1 分钟
... 次阅读

unique_ptr 如何转移所有权 

1
2
3

auto p1 = std::make_unique<int>(10);

auto p2 = p1;   // ❌ 不允许

如果真的要把所有权交给别人

1
2
3

auto p1 = std::make_unique<int>(10);

auto p2 = std::move(p1);

这是转移所有权,而不是复制所有权

shared_ptr 如何跨作用域持有对象

最后一个拥有该对象的 shared_ptr 被销毁后，对象才会被释放。

1
2
3
4
5
6
7

std::shared_ptr<int> p1;

{
    auto p2 = std::make_shared<int>(10);

    p1 = p2;
}

这个时候p2的{}结束了,但是int没有被删掉,因为此时对象还有p1持有
