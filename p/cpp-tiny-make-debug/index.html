$(MAKE) 是什么？

原注释：

这个 MAKE 变量是什么？-B？

$(MAKE) 是 GNU Make 提供的特殊变量，通常用于在一个 Makefile 的配方中递归调用 Make。

当前 .debug 目标执行的核心动作是：

1
2
3
4
5
6

9

make .debug
    ↓
$(MAKE) -B all CXXFLAGS=...
    ↓
再次执行 Make
    ↓
使用指定编译选项重新构建 all
    ↓
生成 tiny_web_server

$(MAKE) 不是 C++ 变量，而是 Make 的变量引用。

-B 为什么需要？

Make 默认根据依赖关系及文件修改时间判断目标是否需要重新构建。

但只改变编译命令中的优化和调试选项，不一定能让普通依赖时间戳检查发现需要重编译。

-B 的作用是强制认为目标需要重新构建。

这适合当前简易 Makefile 中的调试构建目标。

-O0、-g 和 TINY_DEBUG 有什么区别？

选项 所属阶段 意义
-O0 编译 关闭大部分优化
-g 编译 生成调试器使用的信息
TINY_DEBUG=1 运行 启用当前程序的诊断打印

这些设置彼此独立。

普通构建也可以启用 debug_trace。

调试构建也不会自动开启 debug_trace。

为什么当前目标叫 .debug？

.debug 是当前 Makefile 作者选择的目标名称，并不是 Make 内置的特殊调试模式。

所以运行的是：

1

make .debug

而不是：

1

make debug

若想命令更直观，可以将目标改为 debug。

同时建议把它加入 .PHONY，表示该目标代表一项操作，而不是生成同名文件。
