辗转求公因数--神奇的余数

2026-03-01
阅读时长: 2 分钟
... 次阅读

思考

当我们要求两个数a和b的最大公因数的时候,我们往往会使用辗转相除法,其中涉及到一个神奇的取模操作,令r = a % b,a是大数,然后更新数据a = b,b = r,不断循环.这题除了使用while循环来写也可以使用递归的方式来写,递归思想是理解本题很重要的东西.

理解递归的关键在于一句话:相信下一次会更好.每次用余数更新数据,其实就是在缩小搜索的范围,不断向取模结果==0来靠近,因为公因数一定比b小,也会比a和b之间的余数小.

如果 a / b = q … r，那么我们可以写成 a = q x b + r。核心逻辑是：如果有一个数 d，它既能整除 a，又能整除 b，那么它一定也能整除r（因为 r = a - qb）。所以继承下去的余数和小数，两个都继承了上一层的特性同时缩小了范围。

模拟实验：我们来想象一个22 x 8的地板要用瓷砖来铺满，但是并不知道那个能铺满的瓷砖的最大是多少，我们首先用8 x 8的瓷砖来尝试，发现剩下来一块地8 x 6，于是我们用6 x 6去铺，依然剩下6 x 2，最后用2 x 2去铺满，结束。有点像斐波那契的那张图。每次更新数据，都会继承了上一份数据的属性，余数代表缩小的范围，上一层的小数被继承了下来。因为是递归嘛，如果最后一层能够搞定，那向前return也能一层层搞定。

余数并不一定能够搞定递归的上一级,但余数一定存在能够搞定递归上一级的可能性.就是抱着这样的信念在不断取模来缩小范围.

int gcd(int a,int b)
{
    int r = a % b;
    if(r!=0)
    {
        return gcd(b,r);
    }
    else
    {
        return b;
    }
}
