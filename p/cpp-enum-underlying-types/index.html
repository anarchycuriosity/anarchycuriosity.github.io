枚举类是编号吗?为什么在debug的print里面要强转int然后输出?

那这么多个相同的变量都可以是1,那把这个类转为1会不会有比如重复的风险?这个或者说这个转化之后的整数我觉得很神秘,所以我一直定义和使用的一个枚举类它的本质只是一个编号?枚举类和普通类有区别吗?比如他不能存什么数据?

如果枚举成员最后都只是整数，那么不同的枚举成员能不能对应同一个整数？如果可以，程序怎么区分它们？enum class 和普通的 class 究竟有什么区别？

先说结论：

enum class 本质上是一种具有独立类型身份、以整数作为底层表示的枚举类型。它不是普通的类，也不会为每个枚举成员创建一个对象。

而且你担心的重复问题确实存在：不同枚举成员可以拥有相同的整数值，C++ 不会自动禁止这种情况。 如果你没有给它们指定数值，C++ 默认从 0 开始递增。

成员名称 底层整数值
need_data 0

header_too_large 3
编译器会知道这个是一个枚举值,所以int x = result; // 错误
但是允许转换

强类型枚举

对于同一个枚举类里面的不同的枚举成员,如果我们把比如need_data和bad_request都赋值为1,那么就会出现无法判断的情况,因为无论如何第一个if分支都会先成立

但是我们允许不同强枚举类里面的成员值相同,因为强枚举本身就能区分它们.但如果我们进行强转的话,就会失去强枚举类带给我们的这个区分能力.

记住

1

parse_result result = parse_result::bad_request;

这里的 result 是一个变量，parse_result 是类型，parse_result::bad_request 是枚举常量。

它不是创建了一个 bad_request 类对象，也不是保存了 "bad_request" 这个字符串。

你以前一直在使用的 parse_result，本质上就是用类型安全的命名数值，替代那些难以理解的魔法数字。

转化的意义是什么

static_cast<int>(result) 的意义，是主动放弃 parse_result 的类型限制，取出它对应的整数值，以便交给只接受整数的接口使用。

在cpp中,底层表示和身份类型是需要被区分的.强转之后数值不变,但是编译器不认了.这样就可以区分不同的业务
